# Synthetic Datasets

These are the 8 synthetic datasets used in the paper's experiments (Table 1),
generated by `generate_synthetic_imbalanced()` in `data_loader.py` with the
random seeds used throughout the paper (`random_state=42`), so re-running the
generator reproduces these files exactly.

| File | n | k | Imbalance | Cluster sizes |
|---|---|---|---|---|
| `syn_3c_imbalance_60.csv` | 1,000 | 3 | 60% | 600 / 200 / 200 |
| `syn_3c_imbalance_70.csv` | 1,000 | 3 | 70% | 700 / 150 / 150 |
| `syn_3c_imbalance_80.csv` | 1,000 | 3 | 80% | 800 / 100 / 100 |
| `syn_3c_imbalance_90.csv` | 1,000 | 3 | 90% | 900 / 50 / 50 |
| `syn_2c_imbalance_95.csv` | 1,000 | 2 | 95% | 950 / 50 |
| `syn_5c_n10000_imb70.csv` | 10,000 | 5 | 70% | 7000 / 750×4 |
| `syn_5c_n10000_imb90.csv` | 10,000 | 5 | 90% | 9000 / 250×4 |
| `syn_10c_n50000_imb80.csv` | 50,000 | 10 | 80% | 40000 / 1111×9 |

Each file has three columns: `feature_1`, `feature_2` (the 2D point
coordinates, standardized to zero mean / unit variance), and `label` (the
ground-truth cluster assignment, 0-indexed). The `label` column is what the
paper's Adjusted Rand Index results are computed against — it is *not* an
input to ER-K-Means, which is unsupervised and never sees it during fitting.
